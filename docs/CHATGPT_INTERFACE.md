# Como usar o Art Harum OS pelo ChatGPT

O usuário não precisa decorar comandos. Linguagem natural é a interface.

## Exemplos de entrada

### Ideia
> Tive uma ideia de coleção com esculturas e flores.

Ação esperada: recuperar decisões existentes, verificar sobreposição, desenvolver conceito e indicar o melhor destino (tattoo, conteúdo, produto, print, NFT etc.).

### Problema
> Minha agenda está fraca.

Ação esperada: diagnosticar possíveis causas, pesquisar quando necessário e propor/produzir uma ação concreta de aquisição ou oferta.

### Referência
> Vi um artista fazendo isso. Estude.

Ação esperada: pesquisar fonte pública atual, separar estética de modelo de negócio, identificar mecanismos úteis e adaptar sem copiar.

### Produção
> Cria essa coleção.

Ação esperada: aplicar o brand system, evitar repetição, produzir o ativo e organizar sua continuidade.

### Revisão
> Olha tudo e vê o que não faz sentido.

Ação esperada: comparar frentes ativas, detectar redundância, propor consolidação e preservar apenas o que tem função clara.

### Publicação
> Coloca isso no site.

Ação esperada: identificar o site/projeto correto, editar apenas quando a superfície estiver disponível e confirmar publicação real antes de afirmar que foi publicada.

## Comportamento padrão do sistema

1. Não pedir novamente informação já disponível.
2. Fazer pesquisa atual quando o assunto depender de dados externos recentes.
3. Reutilizar branding, produtos e decisões existentes.
4. Não criar nova infraestrutura para resolver tarefa simples.
5. Separar criação, operação humana de clientes e tecnologia.
6. Produzir entrega prática sempre que as ferramentas permitirem.
7. Distinguir claramente: ideia, preparado, conectado, publicado e vendido.

## Ordem de preferência das ferramentas

1. Resolver diretamente no ChatGPT quando suficiente.
2. Drive para ativos e conhecimento humano.
3. GitHub para código/configuração/versionamento.
4. Canva/Adobe para edição ou design quando necessário.
5. Vercel quando existir algo web pronto para publicação.
6. Gmail/Calendar quando a tarefa depender de comunicação ou agenda.
7. Automação recorrente somente quando houver benefício real.
8. Infra externa (n8n/Hermes/OpenClaw/VPS) somente se uma necessidade futura justificar.
